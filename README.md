# Acceler · Portfolio de vídeo

Landing pública con los mejores vídeos editados por Acceler (YouTube, reels, anuncios de Meta, VSL y clases).

- Página: `index.html` (HTML + CSS + JS sin build; GSAP, Lenis y Google Fonts desde CDN).
- Vídeos web: `assets/videos/` (H.264 720p, fragmentos de 30-90 s) y pósters en `assets/posters/`.
- Herramientas: `tools/enc.sh` (transcodificar un vídeo y sacar su póster), `tools/showreel.py` (montaje del hero).
- Originales en Google Drive: `Mi unidad/Acceler - Portfolio vídeo/`.

Publicado con GitHub Pages: https://acceler-mkt.github.io/
